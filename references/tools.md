## 包装器

* [Chef WP-CLI](https://github.com/francescolaffi/chef-wp-cli) - 使用 Chef 进行 WordPress 配置
* [node-wp-cli](https://github.com/gtg092x/node-wp-cli) - 适用于 WP-CLI 的 Node JS 包装器
* [Puppet WP-CLI](https://github.com/rmccue/puppet-wp) - 使用 Puppet 进行 WordPress 配置
* [wpcli gem](https://github.com/hasanen/wpcli) - 从 Ruby 运行 WP-CLI 命令
* [wplib](https://github.com/szepeviktor/wplib) - 用于管理多个站点的 shell 脚本
* [wpcli helpers](https://github.com/charleslouis/wp_cli_helpers) - 一系列节省时间的 shell 别名和函数
* [cPanel-wp-management](https://github.com/MarioKnight/cPanel-wp-management) - 用于遍历 cPanel 服务器上所有账户的 shell 脚本
* [Plesk WordPress Toolkit](https://www.plesk.com/wp-toolkit/) - 由 WP-CLI 支持的 WordPress 安装管理界面
