# wp theme delete

删除一个或多个主题。

**别名：** `uninstall`

从文件系统中移除一个或多个主题。

### 选项

有关所用语法约定的详细说明，请参阅 [参数语法](https://make.wordpress.org/cli/handbook/references/argument-syntax/) 参考。

[&lt;theme&gt;...]
: 要删除的一个或多个主题。

[\--all]
: 如果设置此参数，将删除除当前活动主题外的所有主题。

[\--force]
: 使用此参数以删除当前活动主题。

### 示例

    $ wp theme delete twentytwelve
    已删除 'twentytwelve' 主题。
    成功：已删除 1 个主题中的 1 个。
