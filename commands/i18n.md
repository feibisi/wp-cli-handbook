# wp i18n

为 WordPress 项目提供国际化工具。

除非被覆盖，这些命令在 `before_wp_load` 钩子上运行，恰好在 WP 加载过程开始之前。

### 示例

    # 为当前目录中的 WordPress 插件/主题创建 POT 文件
    $ wp i18n make-pot . languages/my-plugin.pot
